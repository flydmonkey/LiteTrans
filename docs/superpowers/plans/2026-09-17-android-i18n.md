# Android 多语言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android 界面、通知、错误和局域网网页支持简体/繁体/英/日/韩；默认跟随系统，对不上用英文；「我的」可选手动语言。

**Architecture:** `values/` 英文为默认回退；`zh-rCN` / `zh-rTW` / `zh-rHK` / `ja` / `ko` 分目录。不建 `values-zh/`。Compose 用 `stringResource`，Service 用 `getString`。手动语言用 `AppCompatDelegate.setApplicationLocales`。

**Tech Stack:** Kotlin、Compose、AndroidX AppCompat 1.7、JUnit4、Robolectric。不改桌面 `src/`。

## Global Constraints

- 规格：`docs/superpowers/specs/2026-09-17-android-i18n-design.md`
- 五种语言 + 跟随系统；系统对不上 → 英文 `values/`
- **禁止** `values-zh/`；繁体用 `values-zh-rTW/` 与 `values-zh-rHK/`（文案相同）
- 应用名各语言均为 `LiteTrans`
- 语言列表项用目标语言自称；「跟随系统」随当前界面语言
- 「我的」顺序：局域网访问、语言、隐私协议、使用条款、关于
- minSdk 29；JDK 17：`JAVA_HOME=/Users/wuyu/.sdkman/candidates/java/17.0.11-amzn`，`ANDROID_HOME=/Users/wuyu/Library/Android/sdk`
- 不改桌面端；不上第三方 i18n 库
- 现有 JVM 单测必须继续通过（断言改为资源 id 或默认英文）

### Task 1: AppLanguage 与 locale 映射

**Files:**
- Create: `android/app/src/main/java/com/videoconverter/android/ui/AppLanguage.kt`
- Test: `android/app/src/test/java/com/videoconverter/android/ui/AppLanguageTest.kt`

**Interfaces:**
- Consumes: 无
- Produces:
  - `enum class AppLanguage { System, ZhCn, ZhTw, En, Ja, Ko }`
  - `fun AppLanguage.languageTag(): String?` — System → `null`；其余 `zh-CN` / `zh-TW` / `en` / `ja` / `ko`
  - `fun AppLanguage.fromTag(tag: String?): AppLanguage` — 空/`null` → System
  - `fun fallbackLanguageForSystemTag(tag: String): AppLanguage` — 用于说明/测试「系统会落到哪套资源」：`zh-CN`/`zh-SG` → ZhCn；`zh-TW`/`zh-HK`/`zh-MO` → ZhTw；`en` 前缀 → En；`ja` → Ja；`ko` → Ko；`fr`/`de`/其它 → En

```kotlin
package com.videoconverter.android.ui

import org.junit.Assert.assertEquals
import org.junit.Assert.assertNull
import org.junit.Test

class AppLanguageTest {
    @Test
    fun tagsRoundTrip() {
        assertNull(AppLanguage.System.languageTag())
        assertEquals("zh-CN", AppLanguage.ZhCn.languageTag())
        assertEquals("zh-TW", AppLanguage.ZhTw.languageTag())
        assertEquals("en", AppLanguage.En.languageTag())
        assertEquals("ja", AppLanguage.Ja.languageTag())
        assertEquals("ko", AppLanguage.Ko.languageTag())
        assertEquals(AppLanguage.System, AppLanguage.fromTag(null))
        assertEquals(AppLanguage.System, AppLanguage.fromTag(""))
        assertEquals(AppLanguage.ZhCn, AppLanguage.fromTag("zh-CN"))
    }

    @Test
    fun unmatchedSystemFallsBackToEnglish() {
        assertEquals(AppLanguage.En, fallbackLanguageForSystemTag("fr-FR"))
        assertEquals(AppLanguage.En, fallbackLanguageForSystemTag("de"))
        assertEquals(AppLanguage.ZhCn, fallbackLanguageForSystemTag("zh-CN"))
        assertEquals(AppLanguage.ZhCn, fallbackLanguageForSystemTag("zh-SG"))
        assertEquals(AppLanguage.ZhTw, fallbackLanguageForSystemTag("zh-TW"))
        assertEquals(AppLanguage.ZhTw, fallbackLanguageForSystemTag("zh-HK"))
        assertEquals(AppLanguage.ZhTw, fallbackLanguageForSystemTag("zh-MO"))
        assertEquals(AppLanguage.En, fallbackLanguageForSystemTag("en-US"))
        assertEquals(AppLanguage.Ja, fallbackLanguageForSystemTag("ja-JP"))
        assertEquals(AppLanguage.Ko, fallbackLanguageForSystemTag("ko-KR"))
    }
}
```

# Android 底部三 Tab：转码 / 历史 / 我的

在现有引导式转码之上加常驻底栏。转码引擎、队列、输出逻辑不变。本设计叠在 [桌面风格 + 引导式三步](2026-09-17-android-desktop-ui-parity-design.md) 上，只改 `ui/`。

## 目标

- 底栏三个 Tab：**视频转码**、**历史记录**、**我的**。
- 当前三步引导整段放进「视频转码」；任务列表从第三步挪到「历史记录」。
- 「我的」是占位页：应用名、版本、「不上传 · 不联网」，以及隐私协议、使用条款、关于。
- 切走再回来，向导步骤、已选文件和裁切都还在。

## 方案

Compose 顶层 `RootTab` 状态，不引入 Navigation。底栏始终贴在系统导航条上方。

```
内容区
下一步 / 开始转码（仅视频转码）
视频转码 | 历史记录 | 我的
```

不采用：Navigation 三 destination、转码时隐藏底栏。

## 视频转码

现有三步：添加 → 格式 → 存放。第三步只留输出目录和「换个位置」，不再列出任务。

点「开始转码」且真正入队或启动泵之后，自动切到「历史记录」。失败（探测未完成、无可导入文件等）留在本页，照旧出提示条。

## 历史记录

标题「历史记录」。列出 `JobStore` 里的任务，复用现有 `JobRow`：进度、取消、再试一次、打开、分享；有已结束任务时显示「清空已完成」。

空态：「还没有转码记录」。

顺序：新任务在上（列表倒序），方便看刚提交的进度。

## 我的

根页：

- 标题「轻转码」
- 版本号（安装包 `versionName`）
- 副文案「不上传 · 不联网」
- 三行入口：隐私协议、使用条款、关于

点开是应用内短文，系统返回或页内「返回」回到根页。不接 WebView、不联网拉文案。

协议正文按产品事实写：本地处理、不上传、不收集账号；使用条款说明需对源文件有权、画质取决于源和预设、可在历史里重试；关于写明本机工具与当前版本号。

## 返回

| 当前 | 系统返回 |
| --- | --- |
| 我的 · 详情 | 我的根页 |
| 视频转码 · 第 2/3 步 | 上一步 |
| 其它 Tab 根页 | 交给系统 |

切到其它 Tab 时，把「我的」详情收回到根页。

## 测试

- Tab 文案、我的三个入口、协议正文含「不上传 / 不会上传」。
- `consumeRootBack`：详情回根页；转码第 2 步回第 1 步；历史根页不消费返回。
- 现有向导纯函数测试继续通过。

## 明确不做

- 我的页里改输出目录或清空历史（历史页已有清空）
- 账号、登录、联网拉取协议
- 改转码参数、队列、输出命名

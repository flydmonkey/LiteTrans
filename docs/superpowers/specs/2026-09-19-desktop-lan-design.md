# 桌面第 4 刀：局域网访问

在已落地的桌面壳（转换 / 历史 / 我的、音频、文档、视频合并）上，接上手机已有的局域网只读媒体库。产品语义以 [桌面端对齐规格](2026-09-19-desktop-mobile-parity-design.md) 的「我的 / 局域网访问」和 [局域网媒体库](2026-09-17-android-lan-media-library-design.md) 为准。

本规格只固定这一批的范围和接法。不改 `android/`、`ios/`（已在 master 的局域网 favicon 提交保持不动）。

## 背景

第 1–3 刀已经有侧栏「我的」（语言 / 隐私 / 条款 / 关于）、`jobs.json` 历史、五种语言。手机端局域网：默认关、口令、绑定局域网 IPv4、端口优先 `17890`、网页四 Tab 成品库。桌面「我的」还没有这一行，也没有 HTTP 服务。

## 目标与约束

- 「我的」默认选中 **局域网访问**。分组：1. 局域网访问、语言；2. 隐私协议、使用条款；3. 关于。
- 局域网运行时，「我的」侧栏项不打数字角标；局域网这一行显示「已开启」。
- 默认关。网页只读：看历史、播放/预览、下载。不提供上传、删除、重命名、开始转码。
- 绑定**这一台电脑的局域网 IPv4**，不听 `0.0.0.0`，不把 `127.0.0.1` 写成给用户看的地址。有线或 Wi‑Fi 均可（不要照搬 Android 只认 `wlan*`）。
- 端口优先 `17890`，连试 10 个。口令去首尾空白；有口令则所有请求带 URL 编码后的 `?k=`，恒等比较（先解码）。
- 关掉开关或退出应用：服务停。下次启动若开关仍开且有地址，再拉起；口令不变。不上开机自启。
- 没有可用局域网 IPv4：开关可拨开，但不听端口，顶栏提示「没有可用的局域网地址」。端口都被占：提示失败原因。
- 外观继续暖灰 `#ecece8` / 墨 `#1f2428` / 橙 `#c45a2a`。网页 CSS/JS 与 Android `LanHistoryPage` 对齐（桌面色已相同）。
- 不引入第三方 HTTP 框架。不与手机同步。不改转换引擎。

## 方案

Rust 域函数（口令、路由、选地址、组 HTML）可测；`std::net::TcpListener` 绑到选中的 IPv4。每次请求从当前 `JobStore` 只读渲染，不另做缓存页。React 只做「我的」这一页的开关、口令、地址、复制、在浏览器打开。

不采用：`0.0.0.0`、mDNS、HTTPS、公网穿透、系统通知、开机自启、把文件拷进缓存再发。

## 设置页

| 控件 | 行为 |
| --- | --- |
| 开关 | 默认关。打开后尝试绑定；失败仍保持意图为开，页内/顶栏说明原因 |
| 口令 | 可留空；失焦或开关变化时保存去空白后的值 |
| 地址 | 仅开关开且已绑定成功时显示 `http://{ip}:{port}/`；有口令则带 `?k=` |
| 复制 | 写入剪贴板 |
| 在浏览器打开 | 用现有 opener 打开该地址 |

无口令时页内一句：同一网络里拿到地址的人可以查看、播放或预览并下载已完成文件。

## HTTP

与媒体库规格相同：

| 方法 | 路径 | 成功 |
| --- | --- | --- |
| GET | `/` | `200` `text/html; charset=utf-8` |
| GET/HEAD | `/m/{jobId}`、`/m/{jobId}/{index}` | 内联；Range `206` |
| GET/HEAD | `/d/{jobId}`、`/d/{jobId}/{index}` | 附件；Range 可 `206` |
| GET | `/favicon.png`、`/favicon.ico` | 应用图标 |

其它方法 `405`。未知路径 `404`。口令错 `401`。只发磁盘上真实存在的完成输出；不跟随符号链接。

## 数据

`settings.json` 增加 `lanShare.enabled`（bool，默认 false）与 `lanShare.token`（string，默认 `""`）。语言合并规则不变：`language` 仅在 `Some` 时覆盖。保存局域网时不要把三模式预设打成 null。

## 测试

- 口令、路由、query、选 IPv4（跳过回环；有线 `en0`/`eth0` 可用）、端口占用连试、HTML 含四 Tab。
- 有口令时缺 `k` 或错 `k` → 401；HEAD 无正文。
- 现有 `cargo test --lib`、`npx tsc --noEmit`、`node scripts/check-locales.mjs` 继续通过。
- 本机冒烟写入报告：开开关后用浏览器打开地址（不要假装点过）。

## 范围外

开机自启、系统托盘、局域网与手机互相同步、上传/改记录、HTTPS。
